# Isaacs rotational operator prefactor

Using `p_rot=(n0 n_R/2pi) I_R A` in Eq. (7)/(27) and paper `k0=n0 omega0/c`, the `n0` factors cancel. The rotational field RHS is `i (omega0/c) n_R (1+i/omega0 d_tau)[I_R A]`. The existing split phase uses the medium wavenumber and differs by `n0-1`; the full candidate uses the vacuum wavenumber. The analogous electronic-Kerr product-operator issue is recorded but not changed in Phase 8A.1.
