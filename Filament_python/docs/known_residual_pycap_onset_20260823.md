# 120 fs PyCAP 成丝起点残余偏差：冻结记录

## 状态

- 记录日期：2026-08-23
- 问题：当前 120 fs 模型相对论文 PyCAP 电子密度起涨位置仍存在约 2–2.4 cm 的残余差异。
- 当前处理：`known_residual_difference / investigation_frozen`
- 决策：在公开信息范围内，暂不继续针对该偏差调参、修改 Raman/电离模型或提交新的超算传播作业，等待后续新证据或新的项目安排。

## 已完成的排查结论

当前模型与论文公开描述在传播方程主体、800 nm 波长、17 GW 峰值功率、0.95 m 焦距、FT90 横向轮廓、空气组分、电子 Kerr、Raman 参数与 Eq. (27) operator、电离/等离子体基本结构等方面均已进行多阶段核查。

其中：

1. 严格 Raman phase ON/OFF 因果测试证明 Raman feedback 对约 2.3–2.4 cm 的起涨提前具有直接因果作用；但后续重新闭合显示当前 Isaacs Raman 参数、kernel、IIR、rotational `D[I_R A]` 以及 complete Eq. (27) 实现均未发现足以解释厘米级偏差的代码错误。
2. 将 electronic Kerr 从 scalar approximation 改为完整 `D[I A]` 后，`1e22 m^-3` onset 仅后移约 0.032 cm，不能解释残余偏差。
3. Popruzhenko 与 Talebpour 电离模型的 matched 120 fs 比较仅造成亚厘米变化，并且方向不足以解释当前约 2 cm 级偏差。
4. 线性传播与 FT90 焦点定义此前已单独检查；当前没有公开证据支持重新定义 vacuum-focus 坐标。

## 当前保留的两个不可闭合/未继续验证因素

### 1. PyCAP 的精确时域输入波形未知

当前代码使用理想化 Gaussian temporal envelope，并由 120 fs FWHM 定义输入脉冲。论文公开信息没有给出用于 PyCAP 计算的完整输入场 `A(t)`、实测谱幅、谱相位、前后沿结构或弱卫星结构。

因此，即使 FWHM、峰值功率和空间轮廓相同，PyCAP 使用的实际时域波形仍可能与当前 Gaussian 假设存在差异。由于强场电离和 Raman/Kerr feedback 对脉冲前沿与局部峰值十分敏感，这种差异可能造成一定的轴向电子密度起涨偏移。

该因素目前无法在缺少原始 PyCAP 输入数据的情况下严格验证。

### 2. PyCAP 可能在一段纯线性传播后才启用完整非线性传播

当前生产算例从输入面开始进行全距离的 nonlinear propagation，因此即使在远离焦点、非线性极弱的区域，也持续计算 Kerr、Raman、电离与等离子体反馈。

另一种可能的实现是：PyCAP 先对输入脉冲进行一段纯线性传播，使场接近焦区后，再开始完整非线性与电离计算。如果其 nonlinear-start plane 位于当前输入面之后，那么最早可发生电离/非线性反馈的位置会被人为限制在更靠近焦点的位置，从而可能使其电子密度起涨曲线相对当前模型后移。

论文公开描述不足以确认 PyCAP 是否采用这种 nonlinear-start strategy、其切换位置在哪里、以及切换时如何传递场和历史响应状态。因此该因素目前也不能被严格验证或排除。

注意：这一可能性仅作为 residual implementation uncertainty 记录，不作为已经确认的 PyCAP 实现事实。

## 冻结理由

当前剩余约 2–2.4 cm 偏差已经无法由已发现且可验证的单一模型错误解释。继续通过无依据的参数扫描或进一步修改 Raman/电离项容易演变为针对 PyCAP 曲线的经验拟合，而不是模型复现。

因此项目在此阶段接受该偏差作为已知残余差异。后续只有在出现以下信息之一时才建议重新打开：

- PyCAP 源码或更详细算法说明；
- 原始 120 fs 输入时域/频谱数据；
- 明确的 nonlinear propagation 起始面说明；
- 能够直接区分当前实现与 PyCAP 的新实验/数值证据。

在上述信息出现之前，本问题不再作为阶段性阻塞项。
